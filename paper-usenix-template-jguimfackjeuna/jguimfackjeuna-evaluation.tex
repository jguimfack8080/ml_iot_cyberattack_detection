\section{Evaluation}\label{evaluation}

\subsection{Experimentelle Konfiguration}

Alle Experimente wurden mit Python~3.12 und scikit-learn auf dem CICIoT2023-Datensatz
durchgefuehrt~\cite{neto2023ciciot2023}.
Der bereinigte Datensatz umfasst 838.602 Instanzen nach Entfernung von 3.078
BACKDOOR\_MALWARE-Eintraegen (670.881 Training, 167.721 Test, Random-Seed~42).
Die Ergebnisse werden in zwei Schritten berichtet: zunaechst mit Standardhyperparametern,
anschliessend mit den durch Grid Search optimierten Parametern.

\textbf{Grid-Search-Konfiguration.}
Die Hyperparameteroptimierung wurde mit \texttt{GridSearchCV} (cv\,=\,3,
Zielfunktion: \ba{}) auf einem stratifizierten Teilmengedatensatz von 8.045 Instanzen
(5 Dateien) durchgefuehrt, um die Rechenzeit zu begrenzen.
Die durchsuchte Grille umfasst: n\_estimators $\in \{100, 200\}$,
max\_depth $\in \{3, 5\}$, learning\_rate $\in \{0{,}05, 0{,}1\}$,
subsample $\in \{0{,}8, 1{,}0\}$ -- insgesamt 16 Kombinationen je Stufe und Pipeline.

\subsection{Ergebnisse Pipeline A -- mit PCA (39 auf 16 Merkmale)}

Die binaere Klassifikation in Stufe~1 erzielt eine \ba{} von 0{,}9971 und einen
makro-gemittelten F1-Score von 0{,}9969.
Die Mehrklassenklassifikation in Stufe~2 erzielt eine \ba{} von 0{,}5480 und einen
makro-gemittelten F1-Score von 0{,}5784.
Die Trainingsdauer betraegt 2.240 Sekunden.

\subsection{Ergebnisse Pipeline B -- ohne PCA (39 Originalmerkmale)}

Die binaere Klassifikation in Stufe~1 erzielt eine \ba{} von 0{,}9993 und einen
makro-gemittelten F1-Score von 0{,}9993.
Die Mehrklassenklassifikation in Stufe~2 erzielt eine \ba{} von 0{,}6301 und einen
makro-gemittelten F1-Score von 0{,}6670.
Die Trainingsdauer betraegt 1.657 Sekunden.

\subsection{Vorlaeufige Interpretation -- Ablation Study}

Die starke Leistung von Stufe~1 in beiden Pipelines (BA jeweils ueber 0{,}997) bestaetigt,
dass der zweistufige Ansatz das Klassenungleichgewicht strukturell effektiv adressiert.
Das Ergebnis stimmt mit den Befunden von Raturi et al.\ \cite{raturi2026exploratory} ueberein,
wonach baumbasierte Modelle auf dem CICIoT2023-Datensatz besonders gut fuer die binaere
Trennung von DoS/DDoS-Verkehr geeignet sind.

Die aktuelle \ba{} von Stufe~2 liegt unterhalb des in Raturi et al.\
\cite{raturi2026exploratory} berichteten Wertes.
Eine moegliche Erklaerung ist, dass die Grid Search auf einem Teilmengedatensatz von
8.045 Instanzen durchgefuehrt wurde, waehrend Raturi et al.\ das vollstaendige Dataset
verwenden.
Ein Reentrainement auf dem Gesamtdatensatz mit den optimierten Hyperparametern ist als
naechster Schritt vorgesehen, um die Erreichbarkeit der Ziel-\ba{} zu pruefen.

Der Leistungsvorsprung von Pipeline~B gegenueber Pipeline~A bestaetigt die Ausgangshypothese:
Die \pca{}-Dimensionsreduktion beeintraechtigt die Mehrklassenklassifikation messbar.
Dieser Befund stimmt mit der Erwartung ueberein, dass die Projektion auf 16 Hauptkomponenten
klassentrennende Information verliert, die bei seltenen Angriffsklassen besonders relevant
ist.
